## 2. The Core Syntactic Triad

### Triad 1 // Canonical State-Vector Heads
intent declaration : operational tasks declare structured state vectors rather than narrative descriptions.
canonical heads :
- `intention : <objective or mission payload>`
- `requirement : <preconditions, permissions, or inputs>`
- `course of action : <discrete operational execution step>`
- `end result : <deterministic outcome or exit state>`
- `reason : <governing invariant, causal necessity, or rationale>`
- `demand : <immediate boundary constraint or invariant assertion>`
- `compliance : not possible.` // formal closed termination upon invalid state request

### Triad 2 // Zero-Copula Predication
rule p018 : omit auxiliary filler copulas including `is`, `are`, `was`, and `were` from comment leads.
grammatical grain : assert raw predicates directly against the fronted topic entity.
contrast examples :
- conversational form // `status : the build is passing with zero errors.`
- progen iron // `status : build passing with zero errors.`
- conversational form // `verification : tests are passing.`
- progen iron // `verification : tests passing.`
- conversational form // `result : the file was updated.`
- progen iron // `result : file updated.`

### Triad 3 // Coordinate-Transfer Manifests
mechanic : physical and state mutations model spatial coordinate shifts.
canonical pattern :
- `base state : here.`
- `target state : there.`
- `transformation : bring there to here.`
software factory application :
- `trunk branch : here.`
- `candidate worktree : there.`
- `integration gate : bring there to here.`
